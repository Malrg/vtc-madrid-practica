# Práctica VTC Madrid

Aplicación estática de estudio con 234 preguntas extraídas de cuatro modelos de la Comunidad de Madrid. Incluye práctica por módulos, errores, favoritos y simulacro de 60 preguntas en 60 minutos.

Las respuestas siguen los modelos originales y pueden contener erratas o referencias antiguas. No es una aplicación oficial.

## Vercel

Importar este repositorio como un proyecto nuevo. La configuración vercel.json sirve la carpeta dist sin compilación. No requiere variables de entorno ni servicios externos.

El progreso se conserva en localStorage del navegador y del dominio utilizado. No se transfiere automáticamente desde el sitio anterior. La privacidad del alojamiento anterior no se transfiere: revisar el acceso del nuevo proyecto antes de compartirlo.
